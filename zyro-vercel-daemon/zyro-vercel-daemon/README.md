# ZYRO Streaming Bot – Vercel Daemon Edition

A Node.js Discord bot packaged as a Vercel Daemon. See [README_SI.md](README_SI.md) for Sinhala setup instructions and important Hobby plan limitations.

**Important:** Vercel Daemons are currently beta. On Hobby, the monthly shared quota is 5 active CPU-hours and 420 GB-hours of provisioned memory. With the minimum 1 GiB daemon instance, the memory quota alone lasts 420 hours (17.5 days) if kept running continuously. This is not unlimited free 24/7 hosting. Outbound Discord voice UDP must be tested after deployment.
